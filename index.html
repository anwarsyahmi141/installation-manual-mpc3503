01
FIRST THINGS FIRST

Find the printer’s IP address

On the Ricoh control panel, open User Tools / Settings, then find the IPv4 address under System Settings → Interface Settings. The menu names can vary a little by configuration.

IT LOOKS LIKE THIS192.168.1.163Write yours down
TIP You can also print a configuration page from the printer’s settings to find its network address.
02
GET THE RIGHT SOFTWARE

Download and extract the driver

Open Ricoh’s support page, choose your region if asked, and select the MP C3503. Download the current Windows PCL 6 driver, then extract the downloaded file.

↓Open Ricoh driver downloadsOfficial Ricoh support · Select your Windows version↗
NOTE Ricoh’s support pages can differ by country. If this page redirects, search Ricoh’s local support site for “MP C3503 driver” and select your Windows version.
03
ADD IT TO WINDOWS

Add the printer by IP address

  1. 1
    Open Settings → Bluetooth & devices → Printers & scanners.
  2. 2
    Select Add device, wait a moment, then choose Add manually when it appears.
  3. 3
    Choose Add a printer using an IP address or hostname, then select Next.
  4. 4
    Set device type to TCP/IP Device. Enter the IP address you noted in Step 1, clear Query the printer if shown, then select Next.
  5. 5
    When asked for a driver, choose Have Disk → Browse. Find the folder you extracted and select the .inf file (often inside “Disk1”).
  6. 6
    Select RICOH MP C3503 PCL 6, continue through the prompts, and choose Do not share this printer unless you need sharing.
✓That’s the setup. Open the printer in Printers & scanners and print a test page.
A FEW QUICK FIXES

Something not quite right?

Most setup snags come down to the connection or driver selection. Try these before starting over.

⌁Windows can’t find the printerCheck the network connection+

Confirm the printer is on and connected to the same network as your PC. Use its IP address in the manual add flow. If the address changes often, ask your network administrator about reserving it.

▤The driver isn’t listedPoint Windows to the extracted files+

Make sure the download is fully extracted; don’t browse inside the ZIP file. In Have Disk, locate the extracted folder and select the matching .inf file. Download the driver again if the folder contains no .inf file.

↻Jobs stay in the queueRestart the print connection+

Restart the printer and PC, then try a test page. Confirm the printer’s current IP address still matches the port Windows is using. A different or changed address can leave jobs waiting.
