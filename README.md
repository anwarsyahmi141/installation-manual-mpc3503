# Ricoh MP C3503 Windows 11 Installation Guide

A small, responsive, static website with a step-by-step guide for installing the Ricoh MP C3503 printer driver on Windows 11.

## Preview locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Create a GitHub repository and push this project to it.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`, then save.

GitHub Pages will publish the site at the URL shown on that settings page.

## Notes

- The guide links to Ricoh support for the current model-specific driver. Driver availability and page URLs can vary by region.
- Ricoh’s Device Software Manager page lists Windows 10 in its supported operating systems. The guide therefore focuses on manually adding a TCP/IP printer and selecting the extracted driver.
- The site is an independent guide and is not affiliated with Ricoh.
